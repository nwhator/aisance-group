# Aisance Group Website

Corporate website for **Aisance Group**, a premier Nigerian diversified holding enterprise providing everyday domestic and institutional solutions across five core divisions.

## Tech Stack

- **Framework:** [Astro](https://astro.build/) (Static Site Generation / Islands Architecture)
- **Language:** TypeScript
- **Styling:** Tailwind CSS with design tokens aligned to `Modern African Heritage Luxury`
- **Integrations:** `@astrojs/sitemap`, `@astrojs/tailwind`
- **Hosting:** Optimized for Vercel Static Deployment

## Brand System

- **Deep Forest Green:** `#12372A` (Foundational containers, headers, primary brand framing)
- **Champagne Gold:** `#C9A24A` (Key-line highlights, high-value accents, borders)
- **Warm Ivory:** `#F7F5EF` / `#FCF9F8` (Structural archival canvas)
- **Sage Green:** `#DDE7E1` (Tonal cards, divider lines, pills)
- **Typography:**
  - Headings: `Cormorant Garamond` / `EB Garamond`
  - Body & UI: `Montserrat`

## Five Core Divisions

1. **Toiletries Production** (`/services/toiletries-production`)
2. **Home & Commercial Cleaning** (`/services/cleaning`)
3. **Dry Cleaning Services** (`/services/dry-cleaning`)

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Local Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```

### 4. Preview Production Build
```bash
npm run preview
```

## Deployment to Vercel

The project is pre-configured for static generation. On Vercel:
- **Framework Preset:** Astro
- **Build Command:** `npm run build`
- **Output Directory:** `dist`
- **Node.js Version:** 18+ or 20+
